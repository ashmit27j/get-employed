A payments app gives cashback as vouchers. There are **n** voucher values c₁, c₂, …, cₙ, all different, and you can use as many vouchers of each value as you like.

In how many ways can you pick vouchers that add up to exactly **X** rupees? Two ways are the same if they use the same number of vouchers of every value, whatever order you pick them in.

The count can be huge, so print it **modulo 10⁹ + 7**.
